\label{sec:method-ff5}

% TODO: Regression specification
The main estimating equation is:
\begin{equation}
  R_{p,t} - RF_t = \alpha_p + \beta_1 \mathrm{MKT}_t + \beta_2 \mathrm{SMB}_t
  + \beta_3 \mathrm{HML}_t + \beta_4 \mathrm{RMW}_t + \beta_5 \mathrm{CMA}_t
  + \varepsilon_{p,t}
  \label{eq:ff5}
\end{equation}
where $\alpha_p$ is the risk-adjusted excess return (alpha) for portfolio $p$.
